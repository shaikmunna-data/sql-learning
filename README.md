# SQL Learning

A structured collection of SQL concepts, practical queries, and exercises for learning SQL

## Topics Covered

- SQL Fundamentals
- SQL Command Categories (DDL, DML, DQL, DCL, TCL)
- SELECT, WHERE, ORDER BY
- Logical Operators
- SQL Functions
- Aggregate Functions
- GROUP BY and HAVING
- CASE Expressions
- Joins
- Set Operators
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Advanced SQL Analytics
- Advanced DML Operations
- Constraints
- Database Design
- Views
- Stored Procedures
- User-Defined Functions
- Transactions
- Database Normalization
- Indexes
- SQL Performance Optimization
- Temporary Tables
- SQL Security

## Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Purpose

To strengthen SQL fundamentals, practice real-world queries, develop problem-solving skills.
